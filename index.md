# Портфолио технического писателя

Демонстрационный проект: руководство пользователя по управлению общими папками в сервисе «Яндекс Диск». Показывает полный цикл работы технического писателя — от исследования и структуры до публикации через docs-as-code.

## Разделы документации

- [Руководство пользователя](user-guide) — основной документ с пошаговыми инструкциями, таблицами прав и схемами процессов.
- [История изменений](release-notes) — пример release notes в формате Added / Changed / Fixed / Removed.
- [Стайлгайд](style-guide) — правила терминологии, тона и оформления, по которым написана документация.
- [Как поддерживать документацию](contributing) — соглашения для тех, кто будет обновлять руководство.

## Что демонстрирует проект

| Навык | Как показан |
| --- | --- |
| **Docs-as-code** | Документация живёт в Git-репозитории, публикуется автоматически через GitHub Pages |
| **Структурирование** | Оглавление, разделы, навигация, разбиение длинного текста на смысловые блоки |
| **Markdown и GFM** | Таблицы, алерты `[!NOTE]` и `[!WARNING]`, раскрывающиеся блоки `<details>` |
| **Mermaid** | Две схемы бизнес-процессов: настройка доступа и удаление общей папки |
| **Работа с терминологией** | Единый глоссарий и стайлгайд в `style-guide.md` |
| **Доступность** | Alt-текст у изображений, осмысленные подписи к рисункам |

## Инструменты

- **Markdown** — разметка документов.
- **Mermaid** — диаграммы и схемы процессов.
- **Git / GitHub** — версионирование и совместная работа.
- **GitHub Pages** — публикация документации как сайта.
- **Just the Docs** — тема оформления для документации.
- **VS Code** — среда редактирования и предпросмотра.
