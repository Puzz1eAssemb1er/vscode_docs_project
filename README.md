# Портфолио технического писателя: руководство пользователя «Яндекс Диск»

Демонстрационный проект для портфолио. Показывает полный цикл работы технического писателя: от структуры документа до публикации через docs-as-code.

## О проекте

**Руководство пользователя по управлению общими папками в сервисе «Яндекс Диск»** — это документ, который помогает читателю:

- разобраться, что такое общая папка и как она работает;
- создать общую папку и пригласить участников;
- настроить права доступа;
- перемещать, переименовывать и удалять общие папки;
- решать типовые проблемы.

Готовое руководство: **[user-guide.md](user-guide.md)**.

## Моя роль

Я выступил в роли технического писателя и выполнил полный цикл работ:

- **Исследование.** Изучил официальную документацию Яндекс Диска, выделил основные пользовательские сценарии.
- **Структура.** Спроектировал логику документа: от общего описания к пошаговым инструкциям и решению проблем.
- **Написание.** Написал текст в едином тоне, с единой терминологией.
- **Визуализация.** Составил две схемы бизнес-процессов на Mermaid: настройка доступа и удаление папки.
- **Редактирование.** Вычитал текст, привёл к единому стилю.
- **Публикация.** Оформил как docs-as-code: репозиторий на GitHub, Markdown, автоматическая отрисовка схем.

## Что демонстрирует проект

- Умение работать с **docs-as-code**: документация живёт в репозитории рядом с кодом, изменения проходят через Git.
- Навык **структурирования** длинного документа: оглавление, разделы, навигация.
- Владение **Markdown** и расширениями GitHub Flavored Markdown: таблицы, алерты `[!NOTE]` и `[!WARNING]`, раскрывающиеся блоки `<details>`.
- Работа с **Mermaid** для визуализации процессов.
- Понимание **границы между пользовательской документацией и документацией для сопровождающих** (см. `CONTRIBUTING.md`).
- Внимание к **доступности**: alt-текст у изображений, осмысленные подписи.
